✥ KITAB CONVERTER · Script → App HTML

1 — Identitas Kitab

Sampul
Jika kosong, sampul pakai gradasi emas-gading default.

2 — Tempel Script

Auto RTL
Auto: Tiap paragraf dipisah 1 baris kosong. Sistem deteksi Arab → hijau RTL, Latin → krem, Terjemah → putih.
Penanda: Tulis === ARAB, === LATIN, === TERJEMAH, === SYARAH untuk panel eksplisit. Contoh ada di tombol “Muat Contoh”.
Tips: Arab terdeteksi otomatis. Untuk rajah/wafaq, tulis dalam blok === RAJAH atau biarkan — akan jadi facsimile box.

3 — Opsi Tampilan

Semua perubahan live. Hasil akhir adalah 1 file HTML Offline — tanpa server, bisa dibuka di HP/laptop, bisa di-print jadi PDF A4.

Bantuan Cepat

Cara pakai:
1. Isi identitas kitab
2. Paste script → Render
3. Klik Unduh .HTML → jadi app mandiri

Format penanda (opsional):
=== JUDUL Judul Bab
=== ARAB teks Arab
=== LATIN transliterasi
=== TERJEMAH terjemahan
=== SYARAH catatan/syarah
=== RAJAH wafaq/gambar (akan jadi kotak facsimile)
=== GAMBAR https://link-gambar.jpg
=== GAP penanda halaman hilang
